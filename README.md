# Baozi Store

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Web Back-End com Java e Spring Boot, da UNINTER.

## Sobre o projeto

API REST para gerenciamento de produtos, clientes e pedidos de uma loja fictícia de pães chineses.

## Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- Postman

## Endpoints

- `/produtos` — gerenciamento de produtos.
- `/clientes` — gerenciamento de clientes.
- `/pedidos` — gerenciamento de pedidos.

A API possui operações de cadastro, listagem, consulta por ID e exclusão.
